# 本地 MVP 0.1.0 交付验收

日期：2026-10-20。交付位置：E:\chatbot。

## 当前状态

本地 MVP 已就绪，账号联调待完成。按用户要求暂缓填写 DeepSeek 密钥和 QQ 扫码，未宣称真实 QQ AI 好友已经上线。

程序使用独立 Conda 环境，复用 AstrBot 4.29.1、陪伴插件 6.7.0、记忆插件 2.3.1、Edge TTS 及框架原有管理界面。没有另写聊天引擎、记忆数据库或前端。

## 已验证

| 项目 | 证据与范围 |
| --- | --- |
| 本机启动与重启 | Conda 环境启动框架；重启后人格和插件保留；仅监听 127.0.0.1:6185 |
| 登录与设置 | 实际 Edge 浏览器登录及受保护 API 访问通过；未登录访问设置返回 401 |
| API Key 设置 | 使用上游设置页密码输入框；源码不包含用户密钥。遮罩不等于文件加密 |
| 插件加载 | 陪伴、记忆插件均已激活，使用固定提交 |
| 记忆数据层 | 真实插件存储写入、查询及重启后读取通过；其他用户、群聊和其他机器人身份无法读取该条私聊记忆。测试的身份解析使用替身，未验证真实 QQ 事件 |
| 启动器保护 | PID 被复用、进程路径不一致时拒绝停止，避免误关其他 Python 程序 |
| 平台适配逻辑 | 上游 QQ 官方适配和主动发送熔断测试通过；采用测试平台对象，无真实消息投递 |
| 语音生成 | 上游 Edge TTS 已实际生成中文 WAV，样例见 verification/语音样例.wav；未验证 QQ 原生语音投递 |
| 定时任务存储 | 原生接口创建禁用任务、列出并删除成功；任务未触发、未发送消息 |

## 使用与数据

- 双击根目录“启动AI好友.cmd”；面板：http://127.0.0.1:6185。
- 本机登录账号按用户要求设置为 deepseek，密码查看“查看登录说明.cmd”。
- 停止使用“停止AI好友.cmd”，保存的数据保留。
- 数据位于 runtime/app/data；日志和登录说明也在 runtime。备份时自行妥善保管，勿公开上传。
- 默认文字回复；陌生联系人主动联系、群聊学习等扩展默认关闭。
- 源码配置压缩包不包含 Conda、运行数据、第三方插件源码或个人凭据，不能代替完整运行目录。

详细操作见 README.md；上游版本和许可边界见 upstream.lock.json 与 THIRD_PARTY.md。
