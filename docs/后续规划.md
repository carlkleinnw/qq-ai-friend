# 后续规划与已确认需求

更新：2026-10-21。按阶段复用 AstrBot 和现有插件推进，各阶段分别做真实账号验收。

1. 定时提醒：本轮验证聊天创建、重复规则、取消、重启保留和真实 QQ 投递。具体证据与限制见《定时提醒.md》和验收记录。
2. 记忆管理：已复用原有面板验证查看、纠正、删除和双机器人隔离；修复传统面板保存时误写权限/状态的问题。使用与边界见《记忆管理.md》。
3. 语音回复：大肥鱼第一版已复用 Edge TTS 和 QQ 原有发送能力，验证语音条投递、播放启动、开关及合成失败回退；GPT大人暂不启用。更强情绪与指定原声仍需后续参考和服务支持，见《大肥鱼语音.md》。
4. 稳定性与日常可用性：本机 0.1.1 已完成连接恢复、消息防重、有限重试与提示、失败提醒保留、备份覆盖修复及隔离恢复；上游指定回归兼容验证通过。具体实测边界见《稳定性验收.md》。
5. 长期运行：已提供可选登录后启动并核对睡眠设置；未默认启用自启动或部署全天在线主机。需要全天在线时，另选主机并验证部署后的行为。
6. 人设阶段：0.2.0 已提供四种可编辑预设、独立机器人编辑、自定义简介与详细人设，复用原生人格与扩展页。当前 QQ 官方接入支持简介手动复制、粘贴；自动读写资料没有找到并验证可用接口，暂未实现，见《人设功能.md》。

后续已追加体贴甜蜜女友，当前共有五种预设；0.3.0 支持在授权 QQ 私聊选择预设、自定义文字、预览后确认保存，与网页同步，并已完成真实手机收发验证。

最后一阶段的用户要求：

- 提供若干可直接使用的预设人设，各有默认简介，允许修改。
- 用户也能自行设计角色背景、性格和语言。
- 在 QQ 创建机器人时，用户填写的可选个人简介可传回作为该机器人的自定义人设；预设人设的简介预先写好、仍可编辑。
- 不同机器人的简介和人设分别保存。
- 已核对官方 SDK 信息类型和现有插件：Persona+ 的资料同步仅适配 NapCat；当前官方 QQ 接入不伪造自动同步成功，先交付可用的复制、粘贴流程。

人设与语言由用户决定。验证技术链路时不擅自重写已有角色；设置成功、模型确认、QQ 接口接受与手机实际收到分别记录。
