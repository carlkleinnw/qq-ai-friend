# 后续规划与已确认需求

更新：2026-10-21。按阶段复用 AstrBot 和现有插件推进，各阶段分别做真实账号验收。

1. 定时提醒：本轮验证聊天创建、重复规则、取消、重启保留和真实 QQ 投递。具体证据与限制见《定时提醒.md》和验收记录。
2. 记忆管理：复用记忆面板，继续验证用户查看、纠正、删除和双机器人隔离的实际体验。
3. 语音回复：复用 Edge TTS 和 QQ 发送能力，验证手机可播放的语音条、切换及失败反馈。
4. 稳定性：处理已知上游测试兼容问题，验证网络恢复、重复消息、错误提示、备份与恢复。
5. 长期运行：根据实际使用选择本机自启动或全天在线主机，单独验证部署后的行为。
6. 最后做预设人设与 QQ 简介联动，不提前实施。

最后一阶段的用户要求：

- 提供若干可直接使用的预设人设，各有默认简介，允许修改。
- 用户也能自行设计角色背景、性格和语言。
- 在 QQ 创建机器人时，用户填写的可选个人简介可传回作为该机器人的自定义人设；预设人设的简介预先写好、仍可编辑。
- 不同机器人的简介和人设分别保存。
- 实施前核对 QQ 是否提供简介读取/更新接口及授权范围，优先复用现有能力；当前尚未实现这项联动。

人设与语言由用户决定。验证技术链路时不擅自重写已有角色；设置成功、模型确认、QQ 接口接受与手机实际收到分别记录。
