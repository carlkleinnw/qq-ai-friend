# 原生配置直达与身份关联（2026-10-23）

> 本文记录发布前的本机排查过程，文中的“未发布”是当时状态。v0.7.0 发行结果与回退入口见 [发行说明](../RELEASE_NOTES.md)。

当前本机已应用。此记录替代之前简化页作为主入口的行为；未发布新安装包，未修改发布仓库或远端代码。

## 三个入口

| 侧栏入口 | 直接打开 | 保留的结构与能力 |
| --- | --- | --- |
| 模型配置 | /#/providers | 原生顶部模型类型分类、左侧提供商、右侧完整配置；API Key、Base URL、高级参数、获取模型列表、自定义模型、已有模型管理 |
| QQ 连接 | /#/platforms | 原生左侧机器人列表、右侧接入详细配置；创建/删除、启停、AppID/密钥、消息接收、会话配置与路由 |
| Agent 连接 | /#/plugin-view/astrbot_plugin_persona_studio/agent | 独立 Agent 页面、独立入口，选择当前范围及 Agent 并保存参数 |

首页、侧栏和顶部三项导航均已调整。旧 model/qq 简化页地址及 manage?section=... 链接跳转到相应原生页面，不要求先进入概览或额外点击。原有 bot_id 参数保留给 QQ 页恢复目标机器人。

模型页自动载入上次选择的可用提供商，没有可恢复项时载入首个原生提供商；没有配置的模型类型仍保留原生空状态。没有重写提供商编辑器、模型列表获取或自定义模型对话框。

## 三个真实机器人

账号标识与对应名称保存在各自本机配置中；公开发行材料不附带私人账号映射。

以上由当前适配器的 AppID 与已登录 QQ 身份核实，三者都有 QQ 来源的名称和头像；没有按列表顺序猜测。身份接口只返回白名单内的身份与状态字段，不返回 AppSecret、模型密钥或人设正文。

原生列表、手机选择器及详情展示真实名称、头像、AppID 与实际 QQ 连接状态；原生适配器运行状态单独标明。头像不可用时保留原生图标。身份刷新失败时明确提示在线状态待确认。

名称和头像的 QQ 平台、QQ 缓存、本机备用来源分别说明。详情中的“QQ 资料与本机显示信息”可只读刷新平台资料，或保存本机备注与 HTTPS 备用头像；不会修改 QQ 平台资料或接入凭据。优先展示 QQ 平台资料。

原来的“机器人名称”字段实际为后端不允许更改的实例 ID，现在明确标为“接入实例 ID（非 QQ 名称）”并只读，避免将 QQ 改名误当成路由 ID 修改。

## 实际保存与恢复

身份展示始终按原生实例 ID 查找，再与后端 AppID 关联，不改变原生表单的数据、载入及保存处理。机器人配置仍通过原生 BotConfigService.update_bot 保存并加载对应适配器；模型服务仍通过原生提供商保存逻辑生效，保留密钥与模型关联。

切换机器人恢复其自身配置，并保存当前选择供刷新恢复；手机端使用同一身份映射。机器人接入有未保存修改时，切换或离开会确认；刷新使用浏览器原生草稿提醒。好友、人设与模型路由继续使用已有原生配置和会话入口，没有重建或清空这些数据。

## 验证结果

- 项目测试：57 项通过，含不匹配 AppID 禁止借用名称/头像，以及 QQ 缓存名称与本机备用头像来源分离。
- verification/native-navigation/checks.json：24 项通过。核对侧栏直接进入原生页面、三台机器人的名称/头像/AppID/实际配置字段、刷新恢复、完整模型分类和控件、自定义模型对话框，以及 Agent 独立入口。
- 使用临时停用机器人，通过原生页面修改接入设置并保存，接口和刷新均读到修改，另一台临时机器人不受影响。使用未被运行模型引用的临时提供商，通过原生页面保存超时参数并验证刷新恢复。
- 临时机器人、自动生成的临时人设/配置/路由、临时模型提供商已清理。测试前后的已有机器人配置和密钥、模型提供商配置和密钥逐项相同。
- verification/native-navigation/final-readonly.json：10 项通过，含最终真实数据页面、手机指定机器人直达与刷新、手机实名选择及配置恢复、完整模型详情自动载入、旧链接跳转、无横向溢出及无浏览器脚本错误。
- JavaScript 语法和界面机械检查通过。页面截图保存在 verification/native-navigation。

未验证：本轮真实 QQ 收发、对真实机器人修改接入后产生的断线/重连投递、真实模型请求和远端模型列表获取、外部 Agent 的实际回答。没有向真实好友发测试消息，没有调用收费模型。原生获取模型列表逻辑保留，本轮只核对入口与实现未被替换，不宣称远端请求已实测。

## 维护

身份展示与选择恢复位于 installer/dashboard/friend-native-bots.js，外层导航位于 friend-panel.js。原生打包组件没有被修改；实际配置逻辑仍由 AstrBot 4.29.1 提供。后续升级原生前端时需复验这些原生控件的选择器。

scripts/apply_panel_layout.py 已纳入新展示资源、版本摘要与覆盖前备份。修改前源码备份位于私人 runtime/backups/native-navigation，部署备份位于 runtime/backups/panel-layout，原有数据备份继续保留。

可重复验证：scripts/verify_native_navigation.py（临时数据隔离保存，不发消息或调用模型），scripts/verify_native_navigation_readonly.py（现有数据只读检查）。
