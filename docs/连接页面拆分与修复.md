## 确认的问题与修复

| 发现 | 处理 |
| --- | --- |
| 三个入口只是同一混合页的分组 | model、qq、agent 三个独立页面，各自只有本职内容；好友设置独立负责人设和聊天开关 |
| 模型服务、原生测试、扫码与密钥编辑需要绕路 | 对应页顶部明确进入原生完整流程；模型页另提供当前范围模型选择、保存与直接测试 |
| Agent 表单遗漏后端已有参数 | 恢复 Dify 变量/代理、Coze 代理、百炼变量/RAG/代理、DeerFlow 认证 Header/思考/规划/子助手/数量/递归/代理；保留既有地址、密钥、超时等 |
| 切换 Agent 会丢弃原类型参数 | 按机器人或完整好友会话保留不同类型参数，切回恢复；密钥留空保留，不返回明文 |
| 原生配置重新加载会删除未知扩展键 | 参数备份使用 AstrBot 持久化偏好存储，已验证服务重启后恢复；失败时一并回滚 |
| 混合表单保存可能提交无关字段 | 模型页只改模型，Agent 页只改 Agent，好友页负责人设与聊天开关 |
| QQ 开关与备注没有草稿保护 | 切换机器人或页面提醒；分别保存时保留另一部分草稿 |
| 保存后读取失败，错误可能被成功提示覆盖 | 保留读取错误，禁用保存，禁止提交旧机器人数据 |
| 并发改动检测不完整 | 版本包含人设内容、工具和技能摘要；QQ 接入增加版本校验，拒绝过期写入 |
| 失效身份可能落到首个机器人 | 明确要求重选；失效好友范围可显式载入机器人默认设置 |
| 状态轮询失败被忽略 | 明确显示读取失败与在线状态待确认 |
| 旧链接与导航不对应 | 分组旧链接自动跳转，独立页面有对应标题与导航状态 |
| 同页只改变机器人或好友地址参数时，内嵌页可能保留上一份配置 | 监听范围参数变化并重新读取；有草稿时允许保留并回到原地址 |

不能确认每个旧版本的完整行为。本轮恢复项只以实际源码、版本记录及 AstrBot 4.29.1 默认配置和接口为依据。模型服务和扫码接入仍由原生完整页面提供，未重新实现这些功能。内置 Agent 的工具、压缩、回退模型等高级参数保留原生完整配置入口，简化页保存不会重置它们。

## 页面

- 模型配置：http://127.0.0.1:6185/#/plugin-view/astrbot_plugin_persona_studio/model
- QQ 连接：http://127.0.0.1:6185/#/plugin-view/astrbot_plugin_persona_studio/qq
- Agent 连接：http://127.0.0.1:6185/#/plugin-view/astrbot_plugin_persona_studio/agent
- 好友设置：http://127.0.0.1:6185/#/plugin-view/astrbot_plugin_persona_studio/manage

首页、侧栏和页面内均有入口。可带 bot_id、完整 umo 指定范围；省略参数时恢复浏览器的机器人及好友选择。QQ 接入始终作用于整个机器人，进入该页不会覆盖已选择的好友范围。身份按实例和 AppID 匹配，好友按完整会话标识隔离。

模型服务、密钥、地址、启停和完整测试从模型页顶部进入；QQ 扫码、AppID 和密钥从 QQ 页顶部进入。直接模型测试使用原生 Provider.test，可能产生模型费用，不向 QQ 发送消息。外部 Agent 保存只证明配置保存与流程加载，不代表网络连通；没有伪造通用 Agent 测试。

## 验证与边界

- 项目测试 55 项通过：范围隔离、人设保护、过期请求、错误输入、失败恢复、Agent 参数及密钥保留、部署幂等性。
- verification/connection-pages/checks.json：31 项全部通过，包括独立内容、直接刷新、手机宽度、保存刷新、服务重启后 Agent 参数恢复、跨页草稿保护、旧链接、读取失败禁用保存、原生完整流程入口和临时数据清理。浏览器脚本错误为 0。
- 原生文件重载及真实消息处理阶段初始化：使用保存的模型、人设，未调用模型或发送消息。
- verification/connection-pages/readonly-checks.json：最终只读检查 17 项通过，含已有机器人切换、真实已有好友自动载入和刷新、QQ 页面往返保留好友范围、同页地址切换及草稿保护、失效身份拒绝和显式恢复默认范围。
- verification/connection-pages/data-preservation.json：备份内原有会话内容、人设与提醒仍保留；已有真实机器人设置保持不变。
- JavaScript 语法检查通过。机械 UI 检查提示源码新页面缺少 style.css：它们在部署时复用 manage/style.css，实际运行页资源和浏览器已验证；并非线上样式缺失。

未验证：本轮真实 QQ 收发、切换其他模型后的真实回复、外部 Agent 网络连通与回答、真实机器人的停用/重连后投递、Webhook。没有向真实好友发送测试消息，没有调用收费模型。已有好友范围的自动加载与刷新由最终只读检查补充；跨机器人隔离以自动化测试为证，不冒充真实跨机器人聊天。

长期记忆、聊天与现有密钥未清空。测试错误不返回第三方异常原文。凭据仍使用本机原生存储，不宣称已加密。

## 备份与维护

修改前源码位于 runtime/backups/connection-pages/20261023-172431，含原页面截图。原生数据备份由 runtime/backups/latest-native.local.json 指向；覆盖文件另存于 runtime/backups/panel-layout。这些属于私人备份，不能公开。

共用逻辑与样式位于 views/manage/app.js、style.css，各独立目录维护自己的 index.html。scripts/apply_panel_layout.py 为每页复制共用资源。Python 更新先停止本项目服务，运行该脚本加 --include-plugin-code，再启动。

scripts/verify_connection_pages.py 使用临时停用机器人，验证中会短暂重启服务，最后清理本轮临时数据；不发 QQ 消息、不调用模型。
