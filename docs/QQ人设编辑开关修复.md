# QQ 人设编辑开关修复

日期：2026-10-23。本机安装目录 E:/AIbot/AI-Friend。

## 原因与改动

QQ 人设指令已经被识别，但原有私聊授权列表为空，导致编辑请求反复被权限校验拦截。原流程要求复制完整 UMO，操作不够直接。

好友人设页面现在提供“允许 QQ 编辑人设”开关，按当前选中的机器人独立保存，无需填写会话标识。开启后任何与该机器人私聊的人都能管理人设；关闭后管理员也不可从 QQ 修改，并取消该机器人的待确认草稿。群聊仍不可编辑，不赋予系统管理员能力。开关变更立即生效，网页仍可管理人设。

预览、十分钟确认、版本冲突检查和原生人格存储均沿用现有实现。旧私聊授权名单不再参与权限判断；旧安装授权参数会提示改用页面开关，不会扩大权限。新安装默认关闭。维护窗口入口和当前使用文档已同步更新。
