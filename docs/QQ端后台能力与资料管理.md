# QQ 端后台能力与资料管理（2026-10-23）

> 本文记录发布前的本机排查过程，文中的“未发布”是当时状态。v0.7.0 发行结果与回退入口见 [发行说明](../RELEASE_NOTES.md)。

目标是让“QQ 连接”管理真实 QQ 机器人。当前已接入的 QQ 官方 WebSocket、AppID/AppSecret 和 botpy SDK 不能提供完整的开放平台账号级后台管理；没有把本机操作伪装成 QQ 端成功。

## 已核实的能力边界

| 操作 | 当前实际能力 |
| --- | --- |
| 查询名称、头像和连接 | 按原生实例与 AppID 读取已接入机器人的 QQ 公开资料和实际连接状态；可重新同步 |
| 创建或绑定 QQ 机器人 | 保留原生官方扫码授权流程，提供 QQ 官方快速注册/创建入口；需要管理员完成 QQ 授权，不能仅凭本机新增记录宣称 QQ 创建成功 |
| 修改 QQ 名称和头像 | 未找到当前公开文档及 SDK 中可由此消息接入调用的写入接口；使用官方基本信息管理流程，保存/扫码/审核/发布以平台实际要求为准，再重新读取 |
| QQ 端删除、注销 | 未接通公开远端删除接口。官方账号是否提供删除、注销或停用入口，以其管理页面和权限为准；本页不宣称已实现 QQ 端删除 |
| 本机接入启停、参数保存、移除 | 原生真实接入控制仍生效；移除本机接入不注销 QQ 机器人，不删除原有本地好友绑定、人设、记忆或聊天数据 |
| 网页自定义名称和上传头像 | 可选辅助功能，明确标注“仅网页显示”，不会向 QQ 提交修改或审核 |

本页接入列表不是管理员 QQ 账号名下的完整机器人清单。要实现全部操作在本页自动写入 QQ，需要官方支持的管理接口和授权集成；不能用 AppSecret 猜测或调用未公开管理接口。

依据：

- [QQ 官方开发文档：基础信息设置](https://github.com/tencent-connect/bot-docs/blob/main/docs/README.md)：描述管理端修改、确认、审核及发布流程。具体账号入口和规则以当前官方管理页面为准。
- [腾讯官方 Python SDK](https://github.com/tencent-connect/botpy/blob/master/botpy/api.py)：当前用户资料是 GET /users/@me，未发现机器人自身名称、头像的写入或应用注销方法。本机已安装版本也已核对。
- [官方管理入口](https://q.qq.com/)；[官方快速注册创建入口](https://q.qq.com/qqbot/openclaw/login.html)。
- 本机 AstrBot 4.29.1 的 platform_service.py 和 qqofficial/login_registration.py：使用官方 q.qq.com 授权创建/绑定流程；本轮没有改写该流程。

## 本次实现

原生机器人详情新增展开的“QQ 机器人资料管理”。平台名称、头像、AppID、实例 ID 和最近一次读取时间单独展示，提供复制 AppID、官方管理入口、创建/绑定入口、操作指引和重新同步按钮。修改和审核必须在官方页面完成，不伪造审核状态；同步成功只表示从 QQ 读取了公开资料。

“可选：自定义名称与头像（仅网页显示）”提供名称编辑、文件选择、预览、移除头像、是否在网页覆盖平台显示的开关，以及明确保存按钮。PNG/JPEG/WebP 最大 2 MB，服务器实际解码、限制像素、移除元数据并规范化为不超过 512 像素的静态 PNG；拒绝 SVG、损坏内容和动画。图片存于现有私人配置，不上传到 QQ，不引入新依赖。

保存显示“保存中／已保存，仅网页显示／失败，草稿保留”；读取 QQ 显示实际读取成功或失败。保留本机草稿的同时可以重新读取平台资料。关闭网页自定义覆盖可恢复平台显示，原 QQ 名称和头像始终单独保留。

接入列表的添加入口标明“添加／绑定”，移除按钮标明“移除本机接入”。原生移除确认补充说明不会注销 QQ 账号；官方增删改查范围在详情中明确说明。

所有自定义数据按 AppID 保存，写入前再次校验原生实例与 AppID；不修改实例 ID、AppSecret、配置路由、好友、人设、记忆和聊天记录。读取资料后先保存缓存，成功才更新 SDK 内存资料，写入失败保持原配置。第三方读取失败不向页面或日志透出可能包含凭据的异常正文。

## 验证

- 项目测试 68 项通过。新增图片安全处理、错误输入、按 AppID 隔离、平台资料与网页覆盖分离、保存失败恢复、读取失败脱敏、头像移除等测试。
- verification/qq-profile/checks.json：15 项通过，覆盖上传预览、真实本机保存、刷新、跨机器人切换、失败草稿、错误同步状态、移除头像、手机显示和已有接入/模型密钥不变。
- 本轮对一个现有真实 QQ 机器人执行了只读 GET 资料同步，成功。未提交 QQ 平台名称头像修改，未创建、注销真实 QQ 机器人，未发送 QQ 消息。
- 原生完整页面回归 24 项通过，最终只读回归 10 项通过。浏览器无脚本错误，JavaScript 语法检查通过。
- 临时测试使用停用机器人；临时机器人、人设、配置和路由已清理。已有真实接入配置、密钥和模型服务配置核对保持不变。

仍不能把本页称为已完成全部 QQ 端自动增删改同步的后台。官方管理流程的真实提交、审核、发布和注销尚未测试，也未伪装为测试通过。

源代码与运行文件已同步到本机；覆盖前备份继续保留在私人 runtime/backups/panel-layout。没有发布安装包或推送远端。
