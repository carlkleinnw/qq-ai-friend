# 网页面板简化与 QQ 实际控制

0.6.0，2026-10-23。保留现有功能、简洁布局和记忆页开场动画。安装和升级时自动应用。

## 页面入口和操作

首页和侧栏固定提供“模型配置、QQ 连接、Agent 连接”，进入所选机器人的对应分组。高级模型服务、密钥、原生连接测试、机器人接入仍可从分组直接进入原页面。

1. 首页选择机器人，核对 QQ 名称、头像、AppID 和实际连接状态。
2. 点击“管理机器人与好友”，选择机器人默认设置或一个已有 QQ 好友会话。未出现的好友需先与对应机器人聊天，面板不凭名称猜测身份。
3. 自动载入该范围实际使用的模型、Agent、人设和聊天开关；修改后保存。切换时提醒未保存草稿，读取失败时禁止保存旧内容。
4. 保存结果区分配置保存、消息流程加载、失败和等待真实消息验证。选择好友会话后在 QQ 发消息，可查看最近请求、响应及发送阶段。
5. QQ 连接分组提供启停、当前接入方式支持的消息接收设置和重连。接入设置作用于整个机器人；是否连上由后续实际连接状态判断。

记忆与记录、提醒、更多保留原有能力；人设库从人设分组进入。保存到人设库不会自动替换正在使用的人设。

## 身份和同步范围

机器人列表自动读取当前安装的 QQ 账号，不在发行源码中预填开发者账号。

按原生实例和 AppID 对应，不按名称或列表顺序推断。重复 AppID 标记冲突并阻止含糊的控制请求。

优先使用匹配 AppID 的已登录 QQ 身份，支持刷新 QQ 名称和头像。当前集成通过腾讯 botpy SDK 的只读 /users/@me 获取资料，没有实现写入 QQ 资料卡。官方 QQ 域名的 HTTP 头像升级为 HTTPS；其他不安全地址不直接展示。

取不到平台资料时明确来源，允许填写本机备注和 HTTPS 备用头像；这些不会修改 QQ 平台资料。WebSocket 状态检查实际连接及会话就绪情况，只有缓存名称不算在线。无法确认持续在线的接入方式显示未知。

## 实际配置与隔离

复用 AstrBot 原生配置、人格管理和消息路由；保存后重新加载对应消息处理流程。会话使用完整标识，包括机器人实例、会话类型及该机器人的好友标识；不按昵称合并好友、聊天记录或记忆。

会话单独配置优先于机器人默认值；页面读取包含会话指定的人设和模型覆盖。修改共享人设时建立当前范围的独立副本；修改好友会话时使用精确路由及原生会话偏好。过期版本拒绝保存，加载失败尝试恢复配置、路由和偏好。已有聊天记录和长期记忆不删除、不跨范围复制。

内置 Agent 使用当前范围选定的模型与人设；外部 Agent 使用它们自身的模型与人设。页面保留必要连接字段，密钥留空保留已存值且不返回明文。配置加载成功不代表外部服务已连通。

## 验证结果

- 项目测试 46 项通过：身份匹配、重复身份、连接状态、会话隔离、保存、共享人设复制、过期请求、失败恢复和连接控制范围等。
- 最终浏览器 15 项通过：三个固定入口、三台机器人的名称/AppID/实际连接/头像、切换和草稿提醒、会话自动载入、刷新恢复、手机无横向溢出、无脚本错误。证据：verification/qq-control/browser-checks.json。
- 真实 QQ 验收成功：通过网页为“可名”的一个现有好友会话保存临时人设。用户发送“面板联调 Q5D4C”，实际收到“【可名已同步Q5D4C】我正在使用网页为这个好友会话保存的人设”。后台观察到请求使用已保存的配置和人设，以及响应和发送阶段。证据：verification/qq-control/live-reply-checks.json。
- 已恢复该会话原配置、路由和偏好，清理临时配置及人设；三个机器人的默认配置及其他已有会话恢复或保持原样。证据：verification/qq-control/restoration-checks.json。

真实验收使用原有 DeepSeek 模型及内置 Agent。未实际验证：切换另一模型后的回复、外部 Agent 连通性、启停或接收开关引起的真实断线与恢复、Webhook，以及同一好友与多个机器人长期聊天的记忆隔离。当前安装只有“可名”的一个已知好友会话；跨机器人路由隔离已有自动化测试，不冒充多个真实会话实测。

消息观测为内存中的最近状态，重启后等待新消息；本次验收证据单独保存。verification/qq-control/private 含原始会话标识和配置快照，只留本机，不应发布。

## 应用与恢复

外层展示位于 installer/dashboard，管理页位于插件 views/manage，人设库位于 views/editor。

静态页面运行 scripts/apply_panel_layout.py 后刷新。控制逻辑更新先停止本项目服务，运行脚本加 --include-plugin-code，再启动；同步 main、bot_registry、binding、connections、control 及配置结构。覆盖前备份至 runtime/backups/panel-layout，没有新增依赖。

“更多 → 查看原版面板”切换当前浏览器会话的外层布局；--restore-original-shell 移除外壳引用。完整恢复插件需从备份恢复匹配的代码和页面。备份可能包含本机设置，应留在私人 runtime 中。

安装器现已集成页面应用；代码回退同时恢复对应版本的面板。发行验证见 RELEASE_NOTES.md。
