# Windows 安装、更新与维护

适用于 Windows 10 / 11 x64。首次安装需要访问 Python 软件源和 GitHub；建议在非 C 盘预留 8 GB，安装器检查至少 4 GB。无需先安装 Python 或 Conda。

## 首次使用

1. 双击 `AI-Friend_Setup_0.7.0.exe`，阅读说明，选择独立文件夹，等待完成。支持中文及带空格的路径。
2. 打开安装完成页或开始菜单中的“维护与更新”，点击“查看登录信息”。全新安装生成独立密码，请勿公开此文件。
3. 点击“启动 / 打开面板”，使用上述账号登录。面板仅监听本机，端口以维护窗口为准。
4. 在“模型提供商”编辑 deepseek，填写自己的 Key 并保存，启用已配置模型。先在网页聊天验证回复。
5. 在“机器人”创建“QQ 官方机器人（WebSocket）”，按原生页面扫码一键创建，确认启用并保存。
6. 在维护窗口“同步 QQ 机器人”，通过原生路由、配置和人格建立对应关系，并配置 QQ 官方底部快捷菜单。重复操作保留已有设置和无关菜单；同名冲突或超出官方菜单数量限制时会提示。
7. 在“好友人设”页面选择机器人，打开“允许 QQ 编辑人设”开关；也可从维护窗口“QQ 人设编辑开关”进入。开启后，任何与该机器人私聊的人都能管理人设，不授予系统管理员权限。每个机器人单独设置，无需复制会话标识。
8. 重新打开 QQ 私聊，底部“人设设置”提供预设列表、自定义、查看、确认和取消；“选择预设”可点选五种预设。部分 QQ 版本直接发送所选指令，其他版本填入输入框后需点击发送。点击自定义后，直接发送下一条文字描述，预览后通过“确认保存”应用；十分钟内有效，取消或发送其他斜杠指令可退出。也可直接发 `/人设`、`/人设 5` 或 `/自定义人设 你的设定`，再 `/确认人设`。网页“好友人设”编辑的是同一份设定。

新用户需要填写自己的 Key、扫码并核对真实手机收发。面板运行不等于 QQ 已投递。QQ 简介采用手动复制、粘贴，目前不会自动读取或修改 QQ 资料。

## 保存自己的预设

在“好友人设”点击“新建自定义预设”，填写名称、简介（可选）和详细设定，点击“预览人设”，确认内容后“保存到预设”。名称最多七个汉字或十四个英文字母，不能与已有预设重名。

保存复用原生人格数据库及插件配置索引，不直接修改正在使用的人设。新预设加入网页下拉列表，并尝试同步已配置机器人的 QQ 底部菜单。手机重新打开私聊，内置五种预设在“选择预设”，新增预设从“预设2”等分组选择；先预览，再确认应用。菜单对机器人所有用户可见，预览完整设定和保存仍要求人设编辑权限。

如果 QQ 接口暂不可用、已有同名菜单冲突或达到官方十项菜单限制，预设仍保存在本机，页面会提示 QQ 尚未同步；可在维护窗口重新“同步 QQ 机器人”。不要为修复菜单而删除 runtime 或覆盖自己的设定。

## 日常维护

桌面入口启动服务并打开面板；“维护与更新”提供状态、停止、QQ 同步与授权、人设、备份、恢复检查、日志、更新和回退。“开启登录后启动”只在当前 Windows 用户登录后后台运行，不自动弹浏览器。电脑关闭、睡眠、断网会影响回复。

若在网页改过账号密码，点“更新本机登录记录”，在密码输入框填写当前信息，验证成功才保存。密码不会传入进程参数。

## 更新与回退

从可信发布者取得新版 EXE，在维护窗口“选择新版安装包”，保留原安装目录；也可直接双击新版覆盖。当前没有自动更新服务器。

安装器先准备依赖，切换前停止所属服务，用 AstrBot 原生导出器备份数据并保存旧程序和环境指针，然后更新、启动检查。普通更新保留 Key、QQ、人设、聊天、记忆和提醒。部署失败会尝试恢复旧程序和原有运行状态。

“恢复上一程序版本”恢复代码及对应环境指针，保留当前用户数据，不倒退新聊天。跨上游引擎 / 数据格式需要专门迁移安装包；手动改过源码时会暂停覆盖。开发目录不会自动转成安装版，请另选目录。

## 备份与卸载

“备份用户数据”使用 AstrBot 原生导出器；“检查备份恢复”在隔离目录实际导入、重导出并检查数据库，不启动那份数据的 QQ 机器人。

实际恢复数据需先保留当前数据，再到原生面板“设置 → 维护 → 备份管理”按提示导入。程序回退与数据恢复是不同操作。

Windows 应用列表或安装目录的“卸载AI好友.exe”可卸载。卸载停止服务、移除程序入口，保留整个 runtime，包括凭据、数据库、环境和备份。重新安装到同一位置可复用。不要公开分享 runtime。

日志：`runtime/installer.log`、`server.stdout.log`、`server.stderr.log`；升级备份：`runtime/upgrades`。日志与备份可能含私人数据，请在本机检查或脱敏后提供。

## 验证边界

本版未做付费代码签名，Windows 可能提示未知发布者；请核对来源和发布的 SHA256。网络失败可重试，已验证的下载保存在所选目录。

验证结果以 `verification/installer-checks.json` 为准。开发机原有 QQ 真机证据不能替代另一位用户在自己电脑和账号上的确认。


## v0.7.0 回退

当前回退基线为 v0.6.0，历史标签和安装包保留在 GitHub Releases。升级后优先从“维护与更新 → 恢复上一程序版本”回退，这会使用本机升级备份恢复程序和原环境指针，保留当前用户数据。不要删除 runtime，不要在有手动代码修改的目录强行覆盖旧安装包。若要恢复历史数据，请单独核对并导入自己的原生备份；代码标签不包含私人数据库。
