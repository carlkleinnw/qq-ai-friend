## 机器人与记忆边界

账号标识与对应名称保存在各自本机配置中；公开发行材料不附带私人账号映射。

本轮使用已安装引擎和当前记忆配置，在隔离数据库中以三个稳定实例、两个测试好友写入六条不同口令。通过实际 `remember`、`recall` 工具和 `on_llm_request` 钩子验证：同一好友跨机器人、同一机器人不同好友的私聊记录均隔离，自己的记录进入请求内容，其他五条不进入。没有使用外部模型生成最终答案。

管理员记忆页可查看不同窗口；这与聊天可见范围不同。`private_pair` 是当前机器人与好友的私有记忆；`bot_self` 是同一机器人的自身时间线，允许用于其不同聊天窗口；`shareable` 是显式允许共享的记录。当前 ACL 规则数为 0，跨窗口情感连续性关闭，群聊采集及召回关闭，未擅自更改这些开关。向量检索关闭，使用基础检索不属于凭据缺失故障。

关闭数据库后在新解释器重新打开，存留记录仍可检索，已删除的测试记录不复活。本地显示名称/头像字段变化、稳定标识不变时关联仍在。QQ 平台真实改名、换头像和审核未操作；本轮两次服务重启后三个真实 QQ 连接均恢复，但没有将测试口令写入生产库来证明真实 QQ 端重启后的回答。

原有记忆页面也完成实际浏览器操作：只把其 API 请求导向独立测试插件中的真实引擎，复用原有页面、编辑器、服务端处理器；点击保存和删除后检索真实变化，刷新保留修改，其他机器人记录保持。没有给生产接口提交测试记忆的编辑或删除请求。生产记忆及时间线记录数量保持。本次检查看到 1 条内部 Bot Personal 占位记录与 10 条时间线，不应将其宣称为三个机器人已经各自形成长期用户记忆。

## 确认并修复的问题

1. **卸载、禁用后插件后台接口未清理。** 原生管理器移除了消息处理器和插件目录，却保留 `registered_web_apis` 中的绑定方法。已在终止、解绑、加载失败清理路径按完整模块归属移除接口，避免旧实例继续可调用；不会按路由字符串前缀误删相近名称插件。安装、重载、启用仍会正常重新注册。
2. **GitHub 在线安装被失效的系统代理连接阻断。** 同一仓库文件直连成功，原下载器代理连接失败即退出。已仅对仓库下载 GET 在代理连接错误时记录原因并直连重试；保持 TLS 验证，未改模型/QQ 代理配置，不重试读超时或 HTTP 业务错误。修复后原生 GitHub 在线安装第三方样例通过。
3. **提醒检查依赖不存在的旧多机器人记录文件。** 改为从当前机器人列表及实际配置读取，覆盖三个机器人，并适配当前任务列表响应格式。当前三者的相关权限和时区检查通过，任务数为 0，投递未测试。
4. **日常检查把列表首位机器人的语音和模型设置标成“大肥鱼”。** 改为按稳定实例分别读取配置，并区分真实 QQ 连接状态和接入进程状态。
5. **上游兼容检查在安装版目录中要求 Git 元数据，直接报错。** 安装版改为核验锁定 ZIP 的 SHA-256 并逐文件对比原始 vendor 源码，然后才运行兼容测试；保留源码检出版原来的 Git 核验。未降低源码完整性要求。
6. **记忆页初始化覆盖用户刚输入的搜索。** 慢加载实测中，用户进入“记忆检视”后，初始化返回又跳回总览。已保留初始化期间用户选择的视图及搜索条件；慢加载测试修复前失败、修复后通过。编辑、保存、刷新及删除流程同步复查通过。

前两项通过固定版本、校验原文的修复脚本落地，原文件已保存在 `runtime/backups/plugin-routes/`、`runtime/backups/plugin-download/`。修复脚本已接入安装初始化流程；遇到上游版本或其他代码变更会拒绝覆盖，不会自动清空配置。

## 验证和证据

- 项目测试：77 项通过（含接口清理、下载重试与消息去重回归）。
- 记忆工具、权限及隔离上游测试：30 项通过。
- 陪伴插件人设路由/记忆关系/跨插件测试：31 项通过。
- 上游兼容验证：106 项通过。原始上游有一个静态检查误把四个全局生命周期/原文保护钩子要求为人设存储钩子；现有兼容脚本核验这四个函数的精确摘要后，仅在临时副本调整静态检查与旧测试夹具。原始测试和生产代码未为凑通过而修改。直接跑原始那组时结果为 76 通过、1 个静态检查失败，保留此区别。
- 原生模型/QQ/Agent 导航及保存浏览器回归：24 项通过；最终只读桌面/手机回归：10 项通过。
- 原有记忆页面浏览器：9 项通过（包含慢加载搜索回归）；Agent 实际页面保存刷新等：7 项通过。
- JSON 证据：`verification/plugin-memory-audit/{inventory,external-install,memory-engine,memory-ui,agent-flow}.json`；提醒和日常检查：`verification/{reminder-readiness,daily-status}.json`。

未验证：真实 QQ 消息往返与重投递、模型自动抽取记忆及最终回复、真实好友提醒投递、外部 Agent 联网运行、语音与收费功能、QQ 平台资料写入/审核。没有向真实好友发送测试消息，没有调用付费模型或插件。原生模型获取列表/连接测试可能访问用户配置的外部服务，本轮没有将其当作已联网成功。聊天历史只核对读取，不改写真实记录。后续真实 QQ 联测或提醒投递须先取得用户同意。
