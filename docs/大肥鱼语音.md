# 大肥鱼声音与语气第一版

2026-10-21：按用户确认的方向，先做好“大肥鱼”，GPT大人维持原来的文字配置和人设。

## 当前效果

- 音色：原有 Edge TTS 的 `zh-CN-XiaoyiNeural`。实时音色列表标注为女声、Lively、Cartoon / Novel，适合作为清亮、轻快的第一版。
- 参数：语速 `+3%`、音高 `+6Hz`、音量 `+0%`；小幅调整，避免刻意尖细。
- 表达：俏皮、略傲娇；安慰时收敛玩笑，认真问题直接回答。闲聊短句和自然标点，减少括号动作、表情和内心 OS 的朗读。
- 发送：大肥鱼默认同时发语音和文字；GPT大人不启用语音。手机已收到 7 秒问候、8 秒安慰语音及各自文字，7 秒语音已点击并验证播放状态。

这是使用现成音色做的风格近似。没有指定某段原视频作为声纹参考，也没有克隆某位配音者。Edge TTS 支持语速、音高和音量参数，但不提供本项目可任意控制的“傲娇/温柔”情绪标签；当前主要通过表达内容、断句和音色形成语气，不能承诺广播剧级表演或与视频原声一致。

固定文案试听：`verification/大肥鱼_声音试听.wav`，约 9.39 秒，单声道 24kHz / 16-bit PCM。真实手机测试的音频和消息保留在私有运行目录，未加入源码包。

## 在哪里调整

1. 登录本机面板 http://127.0.0.1:6185。
2. 修改声音：进入“模型提供商”，找到 `edge_tts_dafeiyu`，调整音色、rate（语速）、pitch（音高）、volume（音量）。保留原有 `edge_tts`，以免影响其他配置。
3. 开关语音：进入“设置”，先选择“大肥鱼独立配置”，在文字转语音设置中开关语音回复。当前启用双输出，关闭语音后继续发文字。
4. 修改说话方式：在“人格”中编辑 qq-friend 的“大肥鱼聊天与朗读风格”段落。原有用户规则和记忆/提醒工具保留，未替换整个人设。

语音合成使用独立的在线服务，不使用 DeepSeek API Key；用于朗读的回复文字会发送到该语音服务。关闭语音即可恢复纯文字。

## 如何复用

音色和角色表达分别保存在 `config/dafeiyu-voice.json`、`config/dafeiyu-speaking-style.md`，通过 AstrBot 原生提供商和机器人配置绑定。将来给 GPT大人添加声音时，可以复用同一条接入和投递链路，再单独选择它的音色与语气，不必重做 QQ、记忆或提醒。

如果后续需要更强情绪表现或具体声线，可接入框架已有的其他 TTS 提供商，再更换该机器人的语音提供商选择。本轮没有安装新语音模型或新合成服务，没有改动上游语音引擎或 QQ 适配器。

维护命令：

```powershell
# 应用或检查固定的第一版配置；已编辑的风格/音色会拒绝覆盖
& ./runtime/conda/python.exe scripts/setup_dafeiyu_voice.py
# 只关闭大肥鱼语音，保留角色和其他设置
& ./runtime/conda/python.exe scripts/setup_dafeiyu_voice.py --disable
# 使用现有适配器重新生成公开试听文件
& ./runtime/conda/python.exe scripts/verify_voice.py --preset config/dafeiyu-voice.json --output verification/大肥鱼_声音试听.wav
```

在面板里自行修改过音色后，直接在面板维护即可，不需再次运行初始化脚本。首次修改前的配置和人设备份在 `runtime/backups/before-dafeiyu-voice.json`，不进入源码包。

## 验证与限制

真实 QQ 已验证语音投递、播放启动、关闭语音时只发文字、重新开启后恢复语音和文字。脚本反复核对 GPT大人配置与人格未变。手机播放证据来自播放标记改变以及 QQ UID 对应的 Android Speech AudioTrack 启动状态；没有将“接口接受”当作“手机收到”，也未声称主观音色已经由用户认可。

项目共 19 项测试通过。其中语音新增测试调用真实上游回复处理阶段，验证双输出、关闭后不调用合成，以及模拟合成服务异常时保留文字。合成失败的回退不代表 QQ 媒体上传失败也保证重试补发；断网恢复、长代码朗读和复杂情绪表现留待后续验证。此前记录的上游测试兼容失败仍保留，19 项通过是本项目测试范围。

语气参考社区项目 [dafeiyu-persona](https://github.com/ERUIHNIYHBKBNF/dafeiyu-persona)，只借鉴角色特征，没有安装其 skill、复制整套提示词或展示推理心声。语音参数能力参考 [edge-tts 官方仓库](https://github.com/rany2/edge-tts)，运行代码仍使用锁定的已安装版本。
