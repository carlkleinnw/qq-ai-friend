# 好友人设使用与验收

版本：0.2.0；日期：2026-10-21。

## 怎么用

1. 双击项目根目录的 `打开人设设置.cmd`，登录面板；也可在左侧扩展功能中打开“好友人设”。
2. 在右上角选择“大肥鱼”或“GPT大人”。页面会读取它当前绑定的原生人格；不会自动替换旧人设。
3. 选择“俏皮人鱼娘 / 温柔倾听者 / 学习搭子 / 理性助手”，点击“载入预设”。简介与详细人设都能修改。载入只是草稿。
4. 或点击“自己设计”，填写任意自然语言。可以只填写简介，也可以填写详细背景、性格、语言和互动方式。
5. 点击“保存人设”。后续新消息按原生人格路由使用这份设定；不改变模型、声音、工具权限和记忆存储。
6. 旧上下文可能影响表现，想开始新一轮聊天可在 QQ 发送 `/new`；长期记忆保留。

“重新读取已保存内容”会重新加载当前人格。切换机器人、载入预设、清空草稿或重新读取前，若有未保存内容，会先让你选择放弃还是继续编辑；保存失败保留当前草稿。其他窗口已修改人格或机器人绑定时，旧页面会拒绝覆盖，请先自行保留草稿再重新读取。

## QQ 简介的使用方式

- 预设附带简短简介，可以自由修改。
- 自定义时可把 QQ 的个人简介粘贴到“个人简介”。保存后该内容会与详细人设一起作为原生系统提示词生效；不需要再调模型生成一遍。
- “复制简介”用于粘贴回 QQ；若浏览器限制剪贴板，页面会选中文字供手动复制。
- 当前没有自动从 QQ 资料卡读取或向其写入简介。官方 Python SDK 的用户信息类型没有简介字段，未找到已验证可用的官方简介读写接口。不能把 NapCat 的资料修改接口用于当前官方 QQ 机器人。
- QQ 的昵称、头像、资料审核和公开简介仍以 QQ 平台实际结果为准；保存本机人设不代表 QQ 公开资料已更新。

## 复用了什么

采用 AstrBot 已有的 `PersonaManager` 及数据库，不新增人设数据库、模型代理、会话路由或记忆引擎。界面使用 AstrBot 原生 Plugin View、主题、登录鉴权和桥接 API；本项目只增加预设、表单与薄适配层。

简介和详细人设在同一条原生 `system_prompt` 中以可读 Markdown 保存，避免两个数据来源不同步。没有简介时原文原样保存。也可继续在原生“人格”页编辑完整提示词；若手动删除了表单分隔格式，下次进入会将全部原文放入“详细人设”，不会丢弃内容。

只更新 `system_prompt`，保留示例对话、工具、技能、错误提示和人格 ID。新界面不切换会话人格，也不为新角色自动开放工具。若多个启用的机器人共用同一人格，会拒绝通过该入口保存，以免连带改变其他机器人；需先用原生“人格”页复制角色，并在各自配置中独立绑定。

更多人格继续用原生“人格”页创建、删除和管理工具；更多机器人继续按《多机器人与人格》配置独立路由。在本插件的原生配置 `bots` 中加入 `{ "bot_id": "机器人实例ID", "name": "显示名称" }` 即可显示新的编辑目标。本入口修改机器人默认人格，不覆盖会话单独指定的人格。

安装：运行 `scripts/setup_persona_studio.py` 后重启服务。脚本只安装本项目的小型插件并初始化编辑目标，重复运行保留已有配置；已安装文件与源码不同会拒绝覆盖，先核对用户改动。没有安装新依赖。备份继续使用现有原生备份入口，无需新备份格式。

## 开源参考与取舍

- [AstrBot Plugin Views](https://docs.astrbot.app/en/dev/star/guides/plugin-pages.html)：直接复用原生扩展页、桥接和鉴权，沿用已有框架的人格管理器。对照当前安装的 4.29.1 源码验证了调用方式。
- [SillyTavern Character Design](https://docs.sillytavern.app/usage/core-concepts/characterdesign/)：参考角色描述中组织背景、性格与互动方式的做法；预设短文本由本项目编写，不引入整个聊天前端或另一套角色数据库。
- [Persona+](https://github.com/Railgun19457/astrbot_plugin_persona_plus)：考察其人格管理与资料同步方案。它说明 QQ 昵称/头像同步仅适配 NapCat；本项目已有人格 CRUD 且使用官方 QQ 接入，因此不安装重复管理和自动切换插件。
- [QQ 官方接入文档](https://bot.q.qq.com/wiki/develop/api-v2/) 与 [官方 SDK 用户信息定义](https://github.com/tencent-connect/botpy/blob/master/botpy/types/user.py)：据此限定简介联动为手动复制、粘贴。缺少字段不能证明平台永远不支持，只说明当前未实现并验证自动同步。

## 本轮验证范围

新增 9 项测试覆盖旧提示词无损保存、简介长度与空内容校验、原生数据库持久化、工具/技能/示例/错误提示保留、其他机器人隔离、过期页面与路由变更拒绝、共享人格保护。完整项目回归 50 项通过，唯一警告仍为上游 audioop 在 Python 3.13 中将弃用，当前环境为 3.12。

真实 Edge 浏览器通过原生插件桥接完成：读取与切换两个机器人、载入预设不自动保存、自定义保存和刷新重读、仅简介保存、并发修改拒绝、草稿保留与放弃确认、空输入校验、HTML 作为文本显示。桌面与 390px 手机宽度无横向溢出，未发现页面脚本错误。保存验收使用临时人格与配置，完成后全部移除；大肥鱼、GPT大人的现有人设、配置与路由核对保持原样。

未调用收费模型、未发送 QQ 消息。验收证明配置、持久化及原生加载链路有效，不承诺任何模型在所有聊天中都完全遵从人设。结果见 `verification/persona-checks.json`，私人截图保留在本机。
