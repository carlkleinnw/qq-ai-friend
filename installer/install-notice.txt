AI好友 Windows 本地安装版

首次安装需要联网下载固定版本的 Python、AstrBot、陪伴及记忆插件。安装过程将校验组件完整性；下载、环境与用户数据放在您选择的磁盘目录。

您需要在安装完成后填写自己的 DeepSeek API Key，并用自己的 QQ 扫码创建机器人。开发者的密钥、QQ 凭据、聊天与记忆不会包含在安装包中。

本程序复用 AstrBot、Conda、NSIS 及相关开源插件。第三方组件保留其作者和许可信息，使用时请遵守各自条款。部分上游插件没有明确的根目录许可证，本安装程序从原仓库下载固定提交，不将其源码重新打包发布；不能由此推定拥有商用或再次分发授权。

覆盖升级会先备份当前程序与原生数据，再切换新版本。卸载默认保留 runtime 中的设置、密钥、聊天、记忆、备份及运行环境，便于重新安装和自行迁移。

此版本是本机运行软件：电脑需要开机、联网并保持程序运行。当前安装包未做代码签名。项目源码与组件来源说明在安装目录内可查阅。
